# fixtures/ — 共享测试数据

"录一次，长期离线复测"。把真实样本放这里，让每个人都能在没有其它设备时对接调试。

## 放什么

| 文件 | 用途 | 谁产出 |
|---|---|---|
| `defultMap.txt` | 一张真实建图样例（小尺寸优先） | 紫派 |
| `udp_*.bin` / 抓包说明 | App↔紫派 UDP 样例包（含心跳、各命令） | App / 紫派 |
| `lcm_*.log` | LCM 录制日志（`lcm-logger` 产出，可 `lcm-logplayer` 回放） | 紫派 |
| `meter_*.jpg` / 短视频 | 仪表样图/样片 + 期望读数（视觉回归用） | 香橙派 |
| `readings_*.json` | 样例识别结果（对接 `../server-api.md`） | 香橙派 |

## 约定

- **小样本进 git**（KB~几 MB）。**超大文件**（长视频、完整数据集）走外部存储/Release，这里只放说明。
- 每类样本配一句说明：怎么录的、对应哪个契约版本、期望结果是什么。
- 模型权重不放这里（见根 `.gitignore`）。
