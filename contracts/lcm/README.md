# LCM 信道契约 · 紫派内部

**版本 v0.1** — 成员 A 主导。`.lcm` 消息的**字段布局以紫派实际定义为准**；本目录登记
**信道清单 + 命令号清单**，供全员对齐（App 的 UDP 命令最终会翻译成这里的 LCM 命令）。

LCM 底层基于 UDP 组播，高带宽低延迟。模块：UDP↔LCM 桥、轮控、导航(SLAM)、雷达。

## 信道清单

| 信道 | 方向 | 回调 / 用途 |
|---|---|---|
| `HOKUYO_LIDAR` | 雷达 → 导航 | `LaserDataHandle`：激光点集，供 SLAM 建图/定位 |
| `POSE` | → 导航 | `PoseDataHandle`：位姿输入修正定位；轮控每 15ms 反馈估算坐标 |
| `ROBOT_CONTROL` | 桥/上层 → 导航 | `RobotCtrlHandle`：功能控制指令（命令号见下表） |
| `CURRENTPOSE` | 导航 → 上层 | 实时当前位姿；也是 App 心跳坐标的间接来源 |
| `PATH` | 导航 → 轮控 | 路径规划输出（速度、角速度），轮控转差速控制 |
| `wheel_ctrl` | 桥 → 轮控 | 建图阶段移动端遥控指令 |

## ROBOT_CONTROL 命令号（设计文档表 3-10）

| commandid | 功能 |
|---|---|
| 7 | 初始化导航模块配置 |
| 10 | 加载地图（带文件名则加载对应，否则默认地图） |
| 20 | 添加目标点（加入 waypoints，触发路径规划线程） |
| 23 | 删除上一个目标点 |
| 30 | 开始建图（SLAM）并定位 |
| 32 | 保存建图（带文件名则命名保存，否则默认名） |
| 124 | 子机请求从主机拉取地图（含主机 IP，大端编码） |
| 125 | 设置全路径规划房间顶点（支持多段） |
| 126 | 取消全路径规划任务 |
| 127 | 启动全息路径规划 |
