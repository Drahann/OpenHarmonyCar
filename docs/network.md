# 网络规划

整套系统基于**局域网**（UDP / HTTP / LCM）。联调时所有设备必须在**同一 WiFi / 路由器**下。
建议备一个**便携路由器**，让"小车局域网"在任何场地都能复现，IP 不随环境变。

## 设备 / 端口分配

> ⚠️ 下表为建议固定方案；请据实填好并保持与代码一致。App 当前硬编码默认 `172.168.11.99`。

| 设备 | 角色 | 建议 IP | 监听端口 | 说明 |
|---|---|---|---|---|
| 紫派 Purple Pi OH | 主控 | `172.168.11.99` | UDP **5001**、HTTP **8000** | 5001=控制/心跳，8000=地图文件 |
| 鸿蒙 App（平板） | 客户端 | DHCP 或固定 `.x` | UDP **5001**（收心跳） | 收发同端口 |
| 香橙派 Orange Pi | 视觉 | 固定 `.x` | （上报到服务器） | SSH 端口 22 便于远程 |
| 服务器 | 视频/数据 | ⚠️ 待定 | ⚠️ 待定 | 见 `contracts/server-api.md` |

- **LCM**（紫派内部）：默认 UDP 组播 `239.255.76.67:7667`，多在本机各进程间，需同子网组播可达。
- 多机器人分布式：子机经命令 124 拉主机地图（HTTP），主机 IP 大端编码在 UDP 包里。

## 远程开发 / 跨网联调

| 设备 | 系统 | 远程方式 |
|---|---|---|
| 平板 / 紫派 | OpenHarmony | **hdc**（HarmonyOS Device Connector）部署、抓日志、推文件 |
| 香橙派 | Linux（昇腾） | **ssh / scp**；摄像头/推理日志 |

不在同一局域网时（异地协作），用 **ZeroTier / Tailscale / frp** 把设备桥到同一虚拟网，
即可复用上面所有基于 IP 的接口做远程联调。

## 检查清单（联调前）

- [ ] 所有设备连同一路由器，互相 `ping` 通。
- [ ] 紫派 `172.168.11.99` 可达，5001/8000 端口在监听。
- [ ] 关闭会拦截 UDP/局域网的防火墙（尤其 Windows 开发机）。
- [ ] App 内目标 IP 配置正确。
