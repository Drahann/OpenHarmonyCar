## 章节速览

1. 项目背景与应用价值 —— 工业仪表巡检、国产化自主可控。
2. 功能设计 —— 7 模块：雷达感知、电机驱动、LCM 通信、路径规划、系统主控、人机交互、仪表识别。
3. 项目实现 —— 硬件（LDS-50C-2 / RPLIDAR A2M8 雷达、兆威电机、Purple Pi OH/RK3566）；
   中间层（OpenHarmony5.0 编译烧录、cp210x/wget/lcm/glib 交叉编译、SLAM 导航、全息路径、分布式地图）；
   应用层（ArkTS App、UDP/HTTP 通信、地图三坐标系、分布式软总线）；仪表识别（YOLOv5s + Simple Baselines 关键点，昇腾 .om）。
4. 演示效果。
5. 特色与创新 —— 全国产化软硬件、交叉编译工具链、ArkTS 外控、分布式软总线、香橙派+昇腾边缘识别。

## 关键技术参数（速查）

- 主控芯片：RK3566（四核 64 位，内置 NPU，INT8/INT16）。
- 仪表识别：4 关键点（表盘中心 / 指针尖端 / 量程最小 / 量程最大），端到端 ~40ms，~15FPS。
- 定位反馈：轮控每 15ms 经 POSE 反馈估算坐标；导航 ~300ms 更新位姿；切线近似，误差 ~10% 内。
