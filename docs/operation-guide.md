# App 操作指南（新 App · 新旧操作对照）

> 面向从**旧 App**（`W:\CarApp\CarApp`）迁移的使用者：每一步给出「旧 App 怎么做 → 新 App 怎么做」。
> 新 App = `app-harmony`（`HomePage` → 参数化 `ControlPage`，取代旧 4 个克隆控制页）。
> ⚠️ 旧 App 有的少数操作新 App 暂未做 UI（最重要的是**建图**），见末尾「差异 / 缺口」。

## 一、整体流程对照

| 阶段 | 旧 App | 新 App |
|---|---|---|
| 启动 | LoadingPage → **SetIPPage** | LoadingPage → **HomePage**「巡检控制」 |
| 连接车 | SetIPPage 逐个填 IP + 点「连接」+「确定」 | HomePage 点「发现设备」自动发现 → 点车卡片 |
| 选模式 | Index 底部选「A\*算法 / 全路径」、「分布式实现」 | HomePage 顶部 3 个 chip |
| 进控制 | Index 点「N 号机器人」→ 对应克隆页 | 点车卡片 → 统一 `ControlPage(mode, ip)` |
| 控制 | 各页：建图→选点→导航 / 摇杆 | ControlPage：连接→选点→导航 / 摇杆（按模式变体） |

## 二、分步操作

### 步骤 1 · 启动
- **旧**：进入后停在 LoadingPage，自动跳到 SetIPPage。
- **新**：进入后到 **HomePage**（标题「巡检控制」），自动开始一次设备发现。

### 步骤 2 · 连接机器人
- **旧**：SetIPPage 里每个机器人一行「N 号机器人的 IP 地址」+ 输入框 + **「连接」**按钮。
  点「连接」→ 发 `cmd0` → 收到该 IP 回包 → 提示**「连接成功」**并打勾。多机：勾**「开启多机器人模式」**，用 **+/−** 加减机器人；「多端协同下第一个机器人作主控机」。最后点 **「确定」**——**全部连上**才进 Index。
- **新**：HomePage 右上 **「发现设备」** → App 向局域网/热点广播，发现的车列成**卡片**（车名 + IP + 在线点），**免手填 IP**。点某卡进入控制（连接在进控制页时建立）。
  - 想手填 IP（公共 AP 客户端隔离 / 固定 IP）：走兜底 **SetIPPage**（输入 IP → `Storage.isValidIp` 校验 → 保存并连接）。
  - ⚠️ 广播发现协议待成员 A 确认（`integration-qa.md` Q5），当前用 `cmd0` 广播兜底，仅联调用。

### 步骤 3 · 选模式（= 旧「算法」）
- **旧**：Index 底部 toolbar 选 **「A\*算法」** 或 **「全路径」**；**「分布式实现」**单独一项。先选算法，否则点车会提示「请先选择一个算法」。
- **新**：HomePage 顶部三个 chip，**先点一个**：
  - **「单机导航」** = 旧 A\*算法（astar）
  - **「全路径覆盖」** = 旧全路径（fullpath）
  - **「多机协同」** = 旧分布式实现（distributed）

### 步骤 4 · 进入控制页
- **旧**：选好算法后，点 **「N 号机器人」**卡片 → 对应克隆页（A\*=distributedsecondPage / 全路径=distriFullPathPage / 分布式=distributedPage）。
- **新**：选好 chip 后，点发现到的**车卡片** → 统一 **`ControlPage`**（一个页面按模式变体）。

### 步骤 5 · 控制页操作

控制页布局（Google Maps 范式）：**全屏地图**打底；**顶栏**=返回 + 当前车 IP/在线点 + 右上「设备」（展开发现列表，连更多车 / 手填兜底）；**右下**=缩放 FAB（＋ / − / ⊙回中）；**右下浮层**=摇杆；**底部**=操作卡（随模式变）。

#### 建图（最先做 · R1 已补回）
- **旧**：控制页「开始建图」(`cmd0`) → 摇杆驱动车跑一圈 → 「结束建图」(`cmd2`，存图 + 加载导航图)。
- **新**：⚠️ A 现在**开机保留上次地图**，且 **`cmd0` 有图时只当心跳、不建图**——所以「开始建图」改发 **`'m'`/0x6d 强制重新建图**（清空旧图从头建）。底部**建图卡**→ 点 **「开始建图」**(`'m'`) → 用摇杆驱动小车探索一圈环境 → 点 **「结束建图」**(`cmd2`) → App 自动拉图显示 → 之后才出现导航/覆盖操作卡。

#### 摇杆遥控（所有模式通用）
- **旧**：**↑ ↓ ← →** 四个方向按钮，按住持续下发（`cmd1`）。
- **新**：圆盘摇杆，**拖动**摇杆头：**上=前进 / 左=左转 / 右=右转 / 松手回中=停**。（协议无后退，下半区按停处理。）每个摇杆独立节流，松手即发停。
- **速度**：摇杆上方有**速度滑块**（10–100%），调前进速度（`cmd1` 的 speed）；进页按 mode 给默认值。

#### 单机导航（astar）
- **旧**（distributedsecondPage）：地图上**选点** → 导航（`cmd3`）；**「重新选点」**重选。
- **新**（mode=astar）：**点地图任意处选目标点**（底部卡用等宽字显示坐标）→ 点 **「开始导航」**（`cmd3`）；**「取消」**（`cmd4`）。再点地图即重选。

#### 全路径覆盖（fullpath）
- **旧**（distriFullPathPage）：① 选算法「牛耕 / 最小生成树」② 点地图选 4 顶点 → 自动覆盖。
- **新**（mode=fullpath，✅ 已补回）：底部卡 ① 选 **算法 chip**（牛耕算法 / 最小生成树 → `cmd102` 的 algNum）；
  ② **点地图选 4 个顶点**（左下→右下→右上→左上，每点发 `cmd104`），满 4 个**自动启动**覆盖；可「重选顶点」/「停止」(`cmd103`)。

#### 多机协同（distributed）
- **旧**（distributedPage）：「查找设备 / 刷新 / 平板 / 返回上级」走软总线找设备 + 划区协同。
- **新**（mode=distributed）：顶栏「设备」加入更多车；**在地图上点两个点**划一个覆盖矩形子区域（→ `cmd107`+`cmd108`）；底部卡显示**各车进度条**。

## 三、差异 / 缺口（诚实说明，含 TODO）

1. **建图（SLAM）—— ✅ 已补回（R1）**：新 `ControlPage` 现有**建图卡**（地图未就绪时显示）：「开始建图」(`cmd0`)→摇杆探索→「结束建图」(`cmd2`)→自动拉图。连接仍不自动发 `cmd0`（避免误触），但建图入口已恢复。见 `archive/feature-parity-review.md` R1 与上文步骤 5「建图」。
2. **本机部署（旧 OnRobotPage）**：旧 App 的「本地机器人部署」（填本机 IP → OnRobotPage）在新架构里改为独立的**车载 agent**（`car-agent`，常驻紫派，不在平板 App 内）。
3. **摇杆后退**：旧有 **↓**，新无（9 字节协议 `MoveDirection` 只有 停/前/左/右）。
4. **隐藏/显示面板**：旧控制页可「隐藏/显示」摇杆，新暂为固定浮层。
5. **手填 IP vs 自动发现**：旧默认手填 + 逐个连接；新默认自动发现，手填退为兜底（SetIPPage）。

## 四、没有真车时的联调
