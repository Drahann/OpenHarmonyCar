## 一分钟速览

- **是什么**：三人全栈自研的工业巡检机器人——平板（鸿蒙）总控 + 紫派（鸿蒙）SLAM/导航/覆盖/轮控 + 香橙派（昇腾）视觉读表。
- **能干什么**：激光自主建图 → A\* 导航 → BCD 全覆盖 → 多机协同分区 → 边缘读表告警 → DeepSeek 分析报告，完整闭环跑通。
- **凭什么**：全栈国产自主可控（零 ROS、零国外云 AI、自训模型）+ 契约化异构协作架构 + 把机器人做成"像地图 App 一样好用"。
- **价值**：踩中"具身智能量产元年"+"人工智能+"+"信创自主可控"三重国家战略；工业巡检市场 2025 约 27 亿、年增 ~16%、电力占 88.54%。
