### 2.3 动效原则（HTML 段的"语法"）

1. **一屏一个主语**：同一时刻只有一个焦点在动，其余已 settle 或未进场。
2. **快进慢停**：进场 0.7–1.0s `power4.out`；镜头级移动 1.4–2.2s `power2.inOut`。
3. **进场三件套**：位移（y +24~32px）＋ 透明度 ＋ **模糊 12px→0**（发布会质感核心配方）。
4. **停留可读**：文案 settle 后静止 ≥1.2s 再切；段末 hold ≥1.2s。
5. **克制**：无 bounce/elastic、无 3D 翻转、无粒子。唯一允许的"活力"= pin/角标落下的轻微 `back.out(1.2)`。
6. **隐形运镜**：每段 `#stage` 全程匀速缓推 1.00→1.03（`ease:none`），模拟 keynote 摄像机。
7. **局部放大（本片重点）**：演示某按钮 / 读数时，对 App 屏容器做 `scale 1→2.0~2.6`、`transform-origin` 落在目标元素中心，1.0–1.4s `power3.inOut` 推近，hold，再拉回。放大期间该元素**触发态**（高亮 / ripple）同步演。

## 4. 技术架构（HTML 引擎）

### 4.0 一句话
单文件 `film.html`（＋本地 `vendor/gsap.min.js`、`vendor/MotionPathPlugin.min.js`），一条 **GSAP 主时间轴**（默认暂停、可逐帧 seek），把 §1 分镜逐场景拼接；浏览器直接播放预览，亦可逐帧导出成 mp4。

```
demo-video/
├── 00-视频制作总纲.md      # 本文档（源头）

```

### 4.2 运行时模型
- `#viewport`（铺满窗口，居中）→ `#stage`（1920×1080，`transform: scale()` 适配窗口、letterbox）。
- `#stage` 内：`#scenes`（各场景层，绝对定位叠放）＋ `#cursor`（虚拟光标/触点）＋ `#captions`（下三分之一字幕层）＋ `#chrome`（播放控件，导出时隐藏）。
- **场景层**：每个场景一个 `<section class="scene" data-id>`，内含 `#cam`（相机层，承载局部放大/平移）→ App 屏 / 概念图 DOM。
- **主时间轴**：`const tl = gsap.timeline({ paused:true })`；每个场景一个 `buildXX(tl)` 把动画 add 到 `tl` 的 label 处；场景间用 `crossfade(tl, fromEl, toEl, dur)` 工具做溶/推。
- **可 seek**：所有动画走 `tl`（无 setTimeout/随机），`tl.time(t)` 即可定位任意帧 → 导出确定。

### 4.3 App 屏复刻（组件函数）
DOM 模板函数（同一套 CSS token，§2.1）：
- `Tablet(screenEl)` 设备外框；
- `HomeScreen(state)`：顶栏（标题/副行/互信钮/视频钮/发现设备钮）、模式 chips、空态（圆环＋spinner/搜索图标）、车卡片（状态点/巡检车/IP/detail/连接·连接中·进入控制）；
- `ControlScreen(mode,state)`：MapCanvas（SVG：暖灰底＋白图纸＋绿等高线墙＋网格＋pin＋轨迹＋覆盖＋分区矩形＋车体）、TopBar（返回/状态胶囊/重新建图/视频钮）、ZoomFabs（＋/−/⊙）、VisionPip（胶囊⇄小窗）、Joystick＋SpeedControl（建图态）、BottomSheet（建图卡 / astar / fullpath / distributed 操作卡 / 载入遮罩）；
- `VisionScreen(state)`：TopBar、视频区（表盘＋检测框＋4 关键点）、ReadingPanel（fps/推理/检测数/表读数）、ReportCard；
- `TrustScreen` / `SetIPScreen`（兜底，轻量）；
- 概念图：`ArchDiagram`、`ProtocolBytes`、`NumbersWall`、`TitleCard`、`SectionCard`。

> **地图渲染**：SVG。墙体用少量平滑多段线（`path` ＋ `Q` 圆角）模拟"平滑等高线"，软填充＋描边；建图"生长"= 逐段 `stroke-dashoffset` / 路径裁剪揭示。**不用 canvas**（SVG 在 4K 更锐、随 seek 确定）。

### 4.4 虚拟光标与放大
- `#cursor`：圆点＋细环触点；移动用 `gsap.to(cursor,{x,y,duration,ease:'power3.inOut'})`；点击=快速 `scale 1→.82→1` ＋ ripple；按钮同步加 `.is-press`/`.is-active`。
- 提供工具 `tapAt(tl, label, targetSel, {then})`：自动把光标移到目标中心、播 ripple、给目标加触发态。
- 相机：`focus(tl,label,targetSel,scale)` 把 `#cam` `transform-origin` 设为目标中心、`scale` 推近；`unfocus()` 拉回 1。

### 4.5 控件与导出
- 预览控件：播放/暂停（空格）、← →（±1s 拖拽）、`R` 重播、进度条（带场景刻度与 id）、`?play=1` 自动播放、`?scene=04b` 跳场调试。
- **导出（两条路，§7 详）**：A) 快速——浏览器全屏播放，OBS/系统录屏；B) 精致——`?record=1` 让页面按 1/60s 步进 `tl.time()`，配 Playwright 截图成 PNG 序列、ffmpeg 合 mp4（4K/60）。

### 4.6 新增 / 改场景的约定
1. 文案改 §3 / §1；2. 在 `film.html` 的 `SCENES` 注册表加/排场景；3. 写 `buildXX(tl)`；4. `?scene=` 单测；5. 跑一遍核对 hold / 放大 / 字幕同步；6. 更新 `PROGRESS.md`。

## 7. 导出为视频

**A · 快速预览 / 录屏**：浏览器全屏打开 `film.html?play=1`，用系统录屏 / OBS 录 1080p60。零依赖，适合给你快速过版。
**B · 精致逐帧（推荐成片）**：`film.html?record=1` 下页面把 `tl` 按 `1/60s` 步进并暴露 `window.__seek(t)`；用 Playwright 逐帧 `screenshot` 出 PNG 序列 → `ffmpeg -r 60 -i %06d.png -c:v libx264 -crf 16 -pix_fmt yuv420p film.mp4`。设计稿即 1080p，可在 `#stage` 放大到 4K 渲染再下采样更锐。录制脚本与命令在 v1 落地后置于 `record/`。
